# Titanic Survival Prediction

## Project Description

This project predicts whether a Titanic passenger survived
using Machine Learning and Deep Learning models.

## Models Used

### Machine Learning
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost

### Deep Learning
- Artificial Neural Network
- 1D CNN

## Features

The Streamlit application allows the user to enter:

- Passenger Class
- Sex
- Age
- Siblings/Spouses
- Parents/Children
- Fare
- Embarkation Port

The application then predicts the passenger's survival
and displays survival probabilities.

## How to Run

Install dependencies:

pip install -r requirements.txt

Train the models:

python train_model.py

Run Streamlit:

streamlit run app.py
